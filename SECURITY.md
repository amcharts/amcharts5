# Security

## Reporting a vulnerability

Please do not report a security problem in a public issue.

Write to contact@amcharts.com instead, with:

* what the problem is and how to reproduce it;
* the amCharts 5 version, and the browser if it matters.

## Which versions get fixes

Fixes go into the latest release of amCharts 5. Earlier releases are not
patched: upgrading to the latest one is how to get a fix.
