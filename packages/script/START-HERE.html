amCharts 5

This folder is the script version of the library: files you load with script tags, with no build step.

1. See what it can do

The examples folder has a gallery that opens straight from disk. Each example runs above its source, as code or as a JSON config, drawn on canvas or as SVG.

Open the examples

2. Put a chart on a page

Copy this folder into your project and load the files you need. index.js always comes first.

<div id="chartdiv" style="width: 100%; height: 500px;"></div>

<script src="amcharts5/index.js"></script>
<script src="amcharts5/xy.js"></script>
<script src="amcharts5/themes/Animated.js"></script>

<script>
  var root = am5.Root.new("chartdiv");

  root.setThemes([
    am5themes_Animated.new(root)
  ]);

  var chart = root.container.children.push(am5xy.XYChart.new(root, {}));

  var xAxis = chart.xAxes.push(am5xy.CategoryAxis.new(root, {
    categoryField: "country",
    renderer: am5xy.AxisRendererX.new(root, {})
  }));

  var yAxis = chart.yAxes.push(am5xy.ValueAxis.new(root, {
    renderer: am5xy.AxisRendererY.new(root, {})
  }));

  var series = chart.series.push(am5xy.ColumnSeries.new(root, {
    xAxis: xAxis,
    yAxis: yAxis,
    categoryXField: "country",
    valueYField: "visits"
  }));

  var data = [
    { country: "France", visits: 1114 },
    { country: "Germany", visits: 1322 },
    { country: "Spain", visits: 711 },
    { country: "Italy", visits: 984 }
  ];

  xAxis.data.setAll(data);
  series.data.setAll(data);
</script>

Every example in the gallery is a page like this one, ready to copy.

3. What is in this folder

File or folderWhat it is
index.jsThe core. Needed by everything else.
xy.js, percent.js, map.js, stock.js, gantt.js, hierarchy.js, flow.js, radar.js, timeline.js, wc.js, venn.jsOne file per chart family. Stock, Gantt, radar and timeline charts also need xy.js, loaded before them. Gantt also needs plugins/colorPicker.js.
themes/Themes, such as Animated.js and Dark.js.
locales/Translations and number and date formats.
plugins/Exporting, JSON configs and others.
geodata/A world map. Other maps are a separate download.
examples/The gallery and every example as a page.
docs/, AGENTS.mdA reference for AI coding agents.
CHANGELOG.md, README.md, LICENSEWhat changed, the overview, and the license. Keep LICENSE with the files.
